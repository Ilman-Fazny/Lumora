## ✦ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm`

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ilman-Fazny/Lumora.git
   cd Lumora
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ✦ Available Scripts

- `npm run dev` — Starts the local development server at `http://localhost:3000` with hot module replacement (HMR).
- `npm run build` — Compiles the optimized production bundle to the `dist/` directory (~52 KB JS + 5 KB CSS gzipped).
- `npm run preview` — Previews the production build locally.
- `npm run deploy` — Builds and publishes the `dist/` folder to the `gh-pages` branch.
